# PROTO

A personal tool for evaluating digital product ideas before building them.

PROTO researches demand and competition signals (currently via Etsy listing 
data) for a product concept, scores potential titles, and guides the 
creation of digital products like workbooks, trackers, and guides.

This is a personal project with a single user (the developer). It is not 
built for, requested by, or intended for use by any third party, and is 
not a commercial product or service.

Status: early development, personal use.
